# My AdBlock (MV3 확장, 2026-10-26)

## 기능
- 유튜브 광고: 플레이어 응답에서 광고 정보 제거 + 남은 광고 자동 스킵(음소거·배속) + 광고 UI 숨김
- 배너: 기본 선택자 + 도메인 차단 + **요소 직접 지정**(팝업 → "요소 직접 지정")
- 팝업: `window.open` / 화면 밖 `<a>` 클릭 차단, 버튼/링크 직접 클릭은 허용, **차단 목록의 "열기"로 수동 열기**, 사이트별 허용
- 사이트별 일시중지, 사용자 차단 도메인 추가

## 구조
- `manifest.json` / `src/background.js` (동적 규칙) / `src/content/*` / `src/ui/popup.*`
- `lists/*.txt` → `node scripts/build-rules.mjs` → `rules/ads.json`
- 테스트: `node test/e2e.cjs` (Playwright, 배너·팝업·피커·규칙 검증)

## 설치 (테스트)
- Chromium 계열: `chrome://extensions` → 개발자 모드 → 압축 해제 로드
- Android: Kiwi Browser 등 확장 지원 브라우저에 zip 설치
- 삼성 인터넷: 애드온 등록 경로 미검증 (별도 확인 필요)
